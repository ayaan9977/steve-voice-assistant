# STEVE Voice Assistant - Quick Start

## 🎯 For Users (Download Ready APK)

### Step 1: Clone & Build
```bash
git clone https://github.com/ayaan9977/steve-voice-assistant.git
cd steve-voice-assistant
```

### Step 2: Build APK

**Linux/Mac:**
```bash
./build-release-apk.sh
```

**Windows:**
```cmd
build-release-apk.bat
```

### Step 3: Install on Phone
1. Locate: `app/build/outputs/apk/release/app-release.apk`
2. Transfer to Android phone
3. Open file & install
4. Grant permissions
5. Enjoy!
