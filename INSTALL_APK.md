3. Build → Generate Signed Bundle/APK
4. Select APK → Next → Choose keystore → Finish

## 📱 INSTALLATION STEPS

1. **Transfer APK to Phone**
   - Copy `app-release.apk` to your Android device
   - Or email it to yourself

2. **Enable Installation from Unknown Sources**
   - Settings → Security → Unknown Sources → Enable
   - Or Settings → Apps → Special Access → Install Unknown Apps → File Manager → Allow

3. **Install APK**
   - Open File Manager
   - Locate `app-release.apk`
   - Tap to install
   - Allow all permissions

4. **Launch App**
   - Find STEVE Voice Assistant in app drawer
   - Tap to open
   - Complete biometric setup
   - Start using!

## 🔧 TROUBLESHOOTING

**Installation fails:**
- Enable "Unknown Sources" in Settings
- Ensure 50MB free storage
- Try downloading again

**App crashes on startup:**
- Clear app cache
- Uninstall and reinstall
- Check Android version (7.0+)

**Microphone not working:**
- Allow RECORD_AUDIO permission
- Check phone microphone
- Restart app

**Biometric not recognized:**
- Add fingerprint in device Settings
- Try setup again
- Use PIN as backup
